# Create Your World

An original voxel survival-adventure sandbox that runs in the browser (Chrome first). You start
with nothing in an endless procedural world: explore biomes, caves and ruins, mine, build, craft
your way from flint to iron, keep warm, fed and watered, and survive the nights and their
creatures.

It is built with [three.js](https://threejs.org), Vite and TypeScript. All textures, models and
sounds are generated by code. The simulation is deterministic (a seeded world, fixed 30 Hz ticks)
and runs the same in the browser, in workers and in plain Node. The design document, in French, is
`docs/conception.md`.

## Getting started

You need Node.js 22.18 or newer and Google Chrome (Edge works too; Firefox and Safari use only
standard APIs but are not the target).

```bash
npm install
npm run dev
```

Then open http://localhost:5173. The main menu offers Play (or Continue), Worlds, New world and
Settings. Worlds are saved in IndexedDB every 30 s, and also when you pause, quit or hide the tab.

## Controls

Keys are bound by their **physical position** (`KeyboardEvent.code`). The same keys work on every
layout: ZQSD on AZERTY is WASD on QWERTY. The game shows your keyboard's own labels, on the
controls card of the first launch and in the hints.

| Action                                 | Physical key (`code`)        | QWERTY label  | AZERTY label   |
| -------------------------------------- | ---------------------------- | ------------- | -------------- |
| Move                                   | KeyW / KeyA / KeyS / KeyD    | W / A / S / D | Z / Q / S / D  |
| Jump (hold: again on each landing)     | Space                        | Space         | Space          |
| Sprint (or forward tapped twice)       | ShiftLeft (KeyW, KeyW)       | Shift (W, W)  | Shift (Z, Z)   |
| Crouch                                 | KeyC                         | C             | C              |
| Mine, attack (hold: charged blow)      | left mouse button            | click         | click          |
| Use, place, eat, drink, open           | right mouse button           | click         | click          |
| Hotbar slot (8 slots)                  | Digit1–Digit8, mouse wheel   | 1–8           | 1–8            |
| Bag and Logbook                        | KeyE or Tab                  | E / Tab       | E / Tab        |
| Throw an item (Shift: the whole stack) | KeyG                         | G             | G              |
| First or third person                  | KeyV                         | V             | V              |
| Debug panel                            | F3, Backquote, IntlBackslash | F3 / `        | F3 (fn+F3) / @ |
| Pause (Esc on a screen closes it)      | Escape                       | Esc           | Esc            |

On the Bag, a chest, a station or the workbench, items move by clicks: a left click takes a stack
onto the cursor, where it follows the mouse, and puts it down (merging, or swapping with another
stack); a right click takes half a stack, or puts one item down; Shift+click sends a stack across
(bag and hotbar, inventory and chest); a click beside the panel throws the stack (right: one item);
1–8 over a slot swaps it with that hotbar slot. Closing the screen puts the cursor stack back.

Click the game to capture the mouse. Esc on the bag, a chest or a station closes it back to play (if
the browser does not capture the mouse again by itself, a light « Click to resume » shows while the
game goes on); only Esc in play opens the pause menu. Ctrl, Cmd, Alt, F5, F11 and F12 are never
bound. The Settings screen changes the controls (rebinding, mouse sensitivity, invert Y, crouch held
or toggled), the graphics (quality preset, render distance, field of view, resolution, particles,
view bob), the four volumes and the interface scale.

## Commands

| Command                                                            | What it does                                                                      |
| ------------------------------------------------------------------ | --------------------------------------------------------------------------------- |
| `npm run dev`                                                      | development server on :5173, with the `__game` hook                               |
| `npm run verify`                                                   | type-check (`tsc -b`), Biome, unit tests, production build and the JS gzip budget |
| `npm run build` / `npm run preview`                                | production build (no hook) and its local preview                                  |
| `npm run lint:fix`                                                 | formats and applies safe lint fixes                                               |
| `npm run test:perf`                                                | performance thresholds under Node: generation, meshing, seams, creatures, culling |
| `npm run test:slow`                                                | both bots over two game days, run twice: identical hashes                         |
| `npm run headless -- --seed=42 --ticks=9000 --bot=wanderMineBuild` | the simulation in plain Node: `{hash, tps, columns, deaths, broken, placed, …}`   |
| `npm run headless -- --ping`                                       | the world worker's code under plain Node                                          |
| `npm run bench`                                                    | minified build with the hook on :4174, for performance measurements               |
| `npm run e2e`                                                      | Playwright: boot, selftest, save and input specs (Chrome locally, Chromium in CI) |
| `npm run e2e:perf`                                                 | the perf spec on the bench build (walk as is and with the CPU ×1.7; local only)   |
| `npm run size`                                                     | the gzip size of every script of `dist` against 400 kB                            |

`--bot` takes `wander` (walks and jumps) or `wanderMineBuild` (wanders, mines, picks up, builds,
climbs out of pits, drinks and eats); `--world=flat|arena`, `--rd=2` and `--serialize` (commands and
events through JSON) are optional. Never run `vitest` without `run` (watch mode never exits), nor
`tsc` without `-b`.

## URL parameters (dev and bench builds)

A deterministic boot: `http://localhost:5173/?seed=42&storage=memory&noLock=1&debug=1&skipMenu=1`.

| Family            | Parameters                                                                                                                                               |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| World             | `seed`, `skipMenu` (a new world, no menu), `world=<id>` (a saved world), `worldType=flat\|arena`, `time` (hour 0–24), `freezeTime`                       |
| Simulation        | `fixedStep` (ticks advance only through automation), `spawns=0\|1` (natural spawns), `grace=0`, `host=serialize`                                         |
| Rendering         | `rd` (render distance), `quality=low\|medium\|high`, `occlusion=0` (no cave culling), `view=quads\|ao\|light\|xray`, `freecam`, `scene=testchunk\|title` |
| Storage and input | `storage=memory\|idb`, `noLock` (no pointer lock, no world lock), `kb=azerty\|qwerty\|qwertz` (labels only), `onboarding=0\|1`                           |
| Simulated faults  | `forceNoWebGL`, `forceNoIdb`                                                                                                                             |
| Tests             | `selftest=m0,m4\|all`, `timing=0` (no wall-clock thresholds, waits ×4), `bench=walk\|fly\|cave\|mobs\|dig\|load`, `mute`, `debug`                        |

`selftest` and `bench` imply `skipMenu` and `noLock`. `onboarding=1` shows the controls card and the
tips as in a new browser; by default they show once per browser, never under automation.

## The `__game` hook (dev and bench builds)

`window.__game` (version 13) drives and inspects the game from the console or Playwright. It is
loaded by a dynamic import and never ships in a production build. Mutations go through the
simulation's `debug.*` commands. With `?fixedStep=1` they apply at once, and `press` advances its
ticks.

| Group            | Entries                                                                                                                                                                                                                                                 |

| sim, time        | `sim.step(n)`, `sim.tick()`, `sim.hash()`; `time.get()`, `time.set(hours)`, `time.freeze(frozen?)`                                                                                                                                                      |
| input, camera    | `input.look(yaw, pitch)`, `input.press(action, ticks)`, `input.release()`, `input.keyLabel(action)`; `camera.get()`, `camera.set(pose)` (free camera), `camera.mode()`, `camera.toggle()`                                                               |
| player           | `get()`, `teleport(x, y\|'surface', z)`, `setStat(stat, value)`, `stats()`, `give(item, count)`, `inventory()`, `equip(slot)`, `kill(cause?)`, `god(on?)`                                                                                               |

## Tests in the browser

Every milestone has a selftest suite (`src/app/selftest/`). `?selftest=all` runs them all in one
boot; a case that needs another setup is skipped, and none may fail. `npm run e2e` boots `all` in
each setup the suites need (`e2e/selftest.spec.ts`), and checks that every case ran in at least one
of them:

| Setup                  | Query                                                      | Runs                                                                                      |
| ---------------------- | ---------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| test chunk scene       | `scene=testchunk`                                          | m1                                                                                        |
| generated, real ticks  | `seed=7&rd=4`                                              | m2, m6, M11 performance, the bot in real time                                             |
| generated, free camera | `seed=7&rd=4&freecam=1`                                    | the fly benchmark                                                                         |
| generated, fixed steps | `seed=7&rd=4&fixedStep=1` (IndexedDB)                      | m9 survival, the objectives walk, the bot, m16 world                                      |
| flat, fixed steps      | `seed=42&worldType=flat&fixedStep=1` (IndexedDB)           | m3, m4, m5, m7 saves and menus                                                            |
| flat, no IndexedDB     | the same with `forceNoIdb=1`                               | m7's banner, m10 combat, onboarding tips, render feel, m12 controls and fuel, m17 scanner |
| flat, natural spawns   | `seed=42&worldType=flat&rd=4&fixedStep=1&spawns=1&grace=0` | m10 spawns                                                                                |
| arena, fixed steps     | `worldType=arena&fixedStep=1` (IndexedDB)                  | m8 items and stations, M11 audio, m13 bag, cursor, Logbook and workbench, m15 water       |

## Try this milestone

**M17 — Fair, living creatures, the Bestiary and the scanner** (plan v2, `docs/conception.md`
« M17 »). `npm run dev`, then open `http://localhost:5173/?skipMenu=1`.

- **Fair movement**: creatures turn at their own rate and move the way they face: sidestep a
  Shellback's charge and it runs past. They run out of breath (then walk), slow down when wounded,
  and a fall hurts them. Sprint after a Trotter: it bolts, tires, then stays wary and watches you.
- **Senses with limits**: a hunter that loses you goes where it last saw or heard you, searches 6 s,
  then gives up; a chase whose blows never land ends after 25 s.
- **Needs**: creatures get hungry and thirsty; they graze plants, drink at ponds and heal when
  sated. Meat left on the ground draws Prowlers and Swarmlings: a bait.
- **Bestiary**: a new tab of the Bag. A creature is met when you see or strike it, studied once a
  scanner studied it or you killed it; its card tells what it is, where and when it lives, what it
  eats, and its numbers once studied.
- **Field Scanner**: craft it by hand (flint, cords, resin) and wear it on your head: look at a
  creature 2 s within 24 blocks and a ring fills around the crosshair; the target panel shows its
  health, breath and state. Without a meeting, a creature is « Unknown creature ».
- **Checks**: `?worldType=flat&fixedStep=1&selftest=m0,m17`.

### Earlier milestones

- **M16, the planet's biomes, caves and ores**: clean borders, crossing caves, flooded and sealed caves under lakes, ores in layers; `?seed=7&rd=4&fixedStep=1&selftest=m0,m16`.
- **M15, water**: flows by levels, falls first, dries up; `?worldType=arena&fixedStep=1&selftest=m0,m15`.
- **M14, block updates, leaves, torches**: a felled trunk's canopy falls, torches hang on walls
  and fall with them, a thin aim beside them; `?worldType=flat&fixedStep=1&selftest=m0,m14`.
- **M13, bag, cursor, Logbook and workbench**: Minecraft-style clicks with a stack on the cursor,
  stacks of 64, the Bag's tabs, a Logbook with search, filter and greyed recipes, the workbench's
  own screen and queue; `?worldType=arena&fixedStep=1&selftest=m0,m13`.
- **M12, controls and fuel**: a held jump jumps again on each landing, forward tapped twice
  sprints, eating slows the player, Esc on a screen goes back to play, fires burn only while they
  work (the campfire's « Keep burning »); `?worldType=flat&fixedStep=1&selftest=m0,m12`.

**M11 — Polish and performance.** `npm run dev`, then open `http://localhost:5173`.

- **Sound**, all synthesized: footsteps by material, a jump, a landing, a splash and swim strokes,
  eating and drinking, the heartbeat under 25 health, crafting, doors and chests, fires and kilns
  crackling, dusk and dawn stingers, and ambiences by biome and hour (insects, marsh, wind, sand)
  that crossfade over 3 s. Caves have drips; under water everything is muffled and bubbles play.
  Try `?time=18.4` for dusk. `__game.audio.log()` lists every sound played, and
  `__game.audio.ambience()` shows the loops and their gains.
- **Feel**: break a grass block and the chips take the biome's tint; hold the left button on stone
  for dust; jump down 3 blocks for a dip and a puff; hit a Trotter for the swing trail; turn
  quickly and the hand lags; sprint for a view 8° wider; a Prowler's blow rolls the view towards
  it. `__game.render.feel()` reads them; Settings turns off the particles and the view bob.
- **First steps**: in a new browser, or with `?onboarding=1`, the controls card shows your
  keyboard's labels, and « Got it » closes it for good. Then one tip each: the first bag, the first
  mining, thirst under 50, the first dusk.
- **Settings**: graphics presets (Low, Medium, High), resolution, particles, view bob, rebinding
  (stored), crouch held or toggled, interface scale.
- **Performance**: caves hide the sections they cannot see, remeshes write into the vertex
  buffers already there, the client's mesh work eases off when frames run long, and `?quality=`
  picks a preset. Measured on the development machine (an M4 Mac), bench build, RD 6, Medium:

  | Measure                                  | Result           | Budget       |
  | ---------------------------------------- | ---------------- | ------------ |
  | `walk` frame work p95                    | 0.7 ms           | ≤ 9 ms       |
  | `walk` intervals over 20 ms              | 0 %              | < 1 %        |
  | `walk` frame work p95, CPU slowed ×1.7   | 1.1 ms           | ≤ 15 ms      |
  | `cave` draws, culling on / `occlusion=0` | 68 / 169 (−60 %) | ≤ 150, −30 % |
  | `dig` edit → mesh on screen, p95         | 18 ms            | ≤ 50 ms      |
  | `load` navigation → playable             | 0.69 s           | ≤ 3 s        |
  | JS gzip (`npm run size`)                 | 333 kB           | ≤ 400 kB     |

  With `npm run bench` and the pane visible, open
  `http://localhost:4174/?seed=42&storage=memory&mute=1&quality=medium&bench=walk` (or `cave`,
  `dig`, `load`, `fly`): the `BENCH` banner shows the result. `npm run e2e:perf` runs them all.
- **Checks**: `?seed=7&rd=4&fixedStep=1&selftest=m0,m11` does the 15 objectives in order while
  the HUD follows. The items an objective names come from the world by real actions: plant fiber,
  sticks and flint are broken out of tall grass, foliage and gravel, the ores are mined in the
  tundra, desert and marsh, the Prowler Sinew is taken from a Prowler struck down with a spear, and
  the cabin is built block by block, door included; crafts, stations, the sip and the night are the
  game's own too. Debug commands only stage the rest: the home pad, the pool and the hunting pit
  (`debug.fill`), a source block beside the player when none is near, the materials no objective
  names (`debug.give`: logs, stone, clay, peat, copper ore, hides, fur, resin), the Prowler and the
  night of the hunt, teleports between stands. `await __game.bot.run()` lets the
  wanderMineBuild bot play 5 minutes (quick with `?fixedStep=1`, the camera following) and reports
  `errors: []`. `?selftest=all` runs every suite.

- **M10, creatures and combat**: the Trotter, Shagback, Prowler, Swarmlings and Shellback, natural
  spawns in the dark only, charged and stealthy blows, loot; `__game.entities.spawn(…)`,
  `?worldType=flat&skipMenu=1&spawns=1&grace=0&time=23`.
- **M9, survival**: the HUD (vials, stamina arc, compass, clock, objectives, effects), water,
  food, cold, heat and toxic air with shelters and worn gear, sleep, death and the Abandoned Pack;
  `__game.player.stats()`, `setStat()`, `kill()`, `god()`.
- **M8, items and stations**: the Bag with its Logbook, chests, workbench, kiln, campfire and
  bloomery, every tier up to iron; `?worldType=arena` has a workshop row.
- **M7, saves and menus**: IndexedDB saves, Worlds with export and import, pause, Save & quit,
  `?world=<id>`, `?forceNoIdb=1`.
- **M6, underground and decoration**: caves, magma, ores by biome, trees, camps and cairns;
  `__game.world.findStructure(key)`, `?view=xray`.
- **M5, light and time**: a 20-minute day, sky and block light, torches; `?time=21`,
  `?view=light`.
- **M4, mining and building**: hold to mine, place, the hotbar, the bag, throwing items.
- **M3, the player**: walking, sprinting, swimming, first and third person, `?freecam=1`.
- **M0–M2**: the scaffold, the voxel core and the streamed terrain.
