# Create Your World

An original voxel survival-adventure sandbox that runs in the browser (Chrome first).
Start with nothing in an endless procedural world: explore, mine, build, craft, fight and survive
the night.

Built with [three.js](https://threejs.org), Vite and TypeScript. All textures, models and sounds
are generated by code.

## Getting started

Requires Node.js 22.18 or newer.

```bash
npm install
npm run dev
```

Then open http://localhost:5173 in Google Chrome.

| Command                             | What it does                                      |
| ----------------------------------- | ------------------------------------------------- |
| `npm run dev`                       | development server                                |
| `npm run verify`                    | type-check, lint, unit tests and production build |
| `npm run build` / `npm run preview` | production build and local preview                |

## Try this milestone

**M0 — Scaffold.** The page shows a spinning textured cube (three procedural pixel-art textures in
one texture array) under the game title. Useful URLs:

- `http://localhost:5173/?selftest=m0` runs the in-browser acceptance checks.
- `http://localhost:5173/?forceNoWebGL=1` shows the "unsupported browser" screen.
